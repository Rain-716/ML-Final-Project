# 评分标准对应说明

本项目按 100 分评分维度组织，方便答辩时逐项说明。

## 一、问题定义与数据处理（15 分）

### 1.1 问题理解与选题（10 分）

- 选题：中文 AI 心理问诊对话。
- 机器学习问题：中文心理求助文本多分类。
- 实际意义：用户在线表达心理困扰时，系统先识别主题/风险，再给出安全提示和相似心理支持回复。
- 为什么用机器学习：心理求助文本表达方式复杂，人工规则难覆盖全部表达；机器学习可从大规模中文对话语料中学习词汇、语义和类别差异。

### 1.2 数据预处理（5 分）

`scripts/01_preprocess_soulchat.py` 独立完成：

- 解析 SoulChatCorpus 多轮文本；
- 清洗 URL、HTML、空白字符；
- 去重与异常长度过滤；
- 构造弱标签；
- 构造数值特征；
- 使用分层抽样划分 train/val/test；
- 输出 `preprocess_stats.json`，便于报告展示数据分布。

---

## 二、建模与训练（30 分）

### 2.1 基准模型与划分（10 分）

- 数据划分：训练集、验证集、测试集，使用随机种子和分层划分。
- 基准模型：`DummyClassifier(strategy="most_frequent")`，作为最低性能底线。

### 2.2 模型选择与复杂度（10 分）

本项目尝试多类算法：

1. DummyClassifier：最低基线；
2. Logistic Regression：强文本分类基准，便于解释；
3. Linear SVM：适合高维稀疏 TF-IDF 特征；
4. SGD Logistic：适合较大文本数据；
5. BERT/MacBERT：上下文语义模型，使用 GPU 微调。

### 2.3 超参数调优（10 分）

- 使用 `RandomizedSearchCV` + 交叉验证；
- 优化目标：`f1_macro`；
- 调参项：TF-IDF ngram、max_features、分类器 C/alpha/penalty 等。

## 三、模型评估与结论（20 分）

### 3.1 评估指标选择（5 分）

分类任务不仅看 Accuracy，还看：

- Macro-F1：各类别同等权重，适合不均衡分类；
- Weighted-F1：考虑类别样本量；
- Precision/Recall/F1：逐类分析；
- 混淆矩阵：观察易混类别。
