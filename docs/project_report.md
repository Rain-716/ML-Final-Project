# 中文 AI 心理问诊对话系统项目报告

## 1. 背景与意义

在线心理支持场景中，用户通常会用自然语言描述焦虑、失恋、学习压力、家庭关系、人际冲突甚至自伤风险。直接让聊天系统自由回复存在两个问题：第一，模型可能不知道用户的主要困扰类型；第二，高风险表达必须优先触发安全提醒，而不能只给普通安慰。因此，本项目设计一个“先分类、再检索支持回复”的机器学习流程。

本项目定位为课程实验系统，不替代心理咨询师、医生或紧急救援。

## 2. 问题定义

本项目将任务定义为**中文心理求助文本多分类**。

- 输入：一段中文心理求助文本，例如“最近考试压力很大，晚上睡不着”。
- 输出：心理求助主题/风险类别，例如“学习/工作压力”。
- 后续动作：根据预测类别检索相似历史样本的心理支持回复，并显示安全提示。

类别包括：高风险求助、亲密关系、学习工作压力、家庭关系、人际社交、情绪困扰、睡眠身心症状、自我成长、其他心理支持。

## 3. 数据集与预处理

### 3.1 数据集

本项目使用 SoulChatCorpus 开源版本。该数据集是中文心理健康对话相关语料，包含多轮用户与心理咨询师风格回复，适合构建心理支持对话系统。

### 3.2 预处理流程

独立脚本：`scripts/01_preprocess_soulchat.py`。

处理步骤：

1. 递归扫描原始目录中的 JSON/JSONL/TXT/CSV 文件；
2. 解析“用户：... 心理咨询师：...”形式的多轮文本；
3. 抽取每一轮用户发言作为分类输入，将对应咨询师回复作为检索回复；
4. 清洗 HTML、URL 和多余空白；
5. 过滤过短、过长、重复样本；
6. 使用关键词规则生成弱标签；
7. 构造文本长度、轮次数、问号数、感叹号数、高风险关键词数等数值特征；
8. 使用分层抽样划分训练集、验证集、测试集。

### 3.3 标签说明

由于 SoulChatCorpus 主要是对话语料而非分类标注表，本项目使用透明关键词规则构造弱标签。弱标签优点是可解释、可复现，缺点是可能存在误标和类别边界模糊。因此报告中所有模型结果应被解释为“课程实验分类效果”，而不是临床有效性。

## 4. 建模方法

### 4.1 基准模型

使用 `DummyClassifier(strategy="most_frequent")` 作为最低性能底线。若复杂模型不能明显超过该基准，说明模型没有真正学到有效模式。

### 4.2 传统机器学习模型

传统模型采用：

- TF-IDF 字符 n-gram 特征；
- 数值特征标准化；
- Logistic Regression；
- Linear SVM；
- SGD Logistic。

中文短文本中分词容易受词典影响，因此字符 n-gram 是稳健选择；同时加入长度、标点和风险关键词计数，使模型能利用简单但有意义的行为特征。

### 4.3 BERT/MacBERT GPU 微调

深度模型使用 `AutoModelForSequenceClassification`，默认预训练模型为 `hfl/chinese-macbert-base`。训练脚本支持：

- CUDA GPU；
- fp16 混合精度；
- 类别权重；
- warmup 学习率调度；
- 梯度裁剪；
- 验证集 Macro-F1 保存最优模型。

BERT 类模型能捕捉上下文语义，理论上对“我撑不住了”“感觉没有出口”等隐含表达更敏感。

## 5. 超参数调优

传统机器学习模型使用 `RandomizedSearchCV` 与交叉验证，优化目标为 Macro-F1。调参包括：

- TF-IDF n-gram 范围；
- TF-IDF 最大特征数；
- Logistic Regression 的 C 和 solver；
- Linear SVM 的 C；
- SGD 的 alpha 与 penalty。

BERT 训练可调节：batch size、学习率、max length、epoch、warmup ratio、梯度累积和 fp16。

## 6. 评估指标与可视化

本项目是多分类任务，而且弱标签分布可能不均衡，因此不只使用准确率，还使用：

- Accuracy；
- Macro-F1；
- Weighted-F1；
- 每类 Precision/Recall/F1；
- 混淆矩阵。

自动生成的图表包括：

- 模型 Macro-F1 对比图；
- 每个模型混淆矩阵；
- 学习曲线；
- BERT 训练损失曲线；
- BERT 验证集 Macro-F1 曲线。

## 7. 交互系统设计

`app.py` 使用 Gradio 搭建 Web Demo。用户输入一句心理求助文本后，系统执行：

1. 危机关键词优先检测；
2. 分类模型预测类别与置信度；
3. 显示安全提示；
4. 在相同类别中检索相似语料回复；
5. 在界面中显示模型来源、置信度和检索相似度。

高风险文本会优先显示安全提醒，避免普通检索回复覆盖危机处理。

## 8. 结论

本项目完成了从数据集下载、独立预处理、传统机器学习基准、GPU 深度模型训练、评估可视化到 Web 交互演示的完整流程。传统模型提供可解释的性能基线，BERT/MacBERT 提供更强语义建模能力，Gradio Demo 能直观展示实时输入、预测结果与回复检索。

## 9. 局限性

1. 弱标签来自规则，可能有误标，不能代表专业心理评估；
2. 数据集中的回复风格可能存在偏差，不能保证适合所有用户；
3. 模型输出不能替代心理咨询师或医生；
4. 高风险识别目前主要依赖关键词和分类模型，仍可能漏判；
5. 检索回复来自历史相似样本，可能缺少个性化干预。

## 10. 改进方向

1. 引入人工标注或专家审核标签；
2. 使用更细粒度的多标签体系，例如情绪、主题、风险等级同时预测；
3. 加入语义向量检索模型，提高回复匹配质量；
4. 对高风险样本做更严格的召回优先训练；
5. 增加日志分析与用户反馈机制，用于持续改进系统；
6. 如果课程允许，可部署到 Hugging Face Spaces、ModelScope Studio 或学校服务器。
